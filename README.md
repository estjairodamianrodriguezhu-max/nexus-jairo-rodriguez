# NEXUS — Proyecto Programación II

## 📝 Descripción del Proyecto
NEXUS es una aplicación desarrollada en C# orientada a objetos para la materia de Programación II. Su objetivo principal es gestionar los procesos centrales del sistema mediante una arquitectura limpia y modular.

## 🚀 Cómo ejecutar el proyecto
1. Clonar el repositorio o descargar el código fuente.
2. Abrir la solución (`.sln`) en Visual Studio 2022 o posterior.
3. Compilar y ejecutar la aplicación presionando `F5`.

## 📚 Documentación Técnica
En la carpeta `/docs` se encuentra el manual técnico completo de la arquitectura del sistema y la guía de estudio para el Hito 3.
